# Esercizi-3M

In questa repository trovate le soluzioni degli esercizi visti in classe.

## Istruzioni

Per compilare il codice il comando è da usare è: `gcc nome_sorgente.c -o nome_eseguibile`

Per eseguire il programma, invece basta scrivere: `./nome_eseguibile`

Con `nome_sorgente.c` e `nome_eseguibile` che devono essere sostituiti in base all'esercizio specifico
